VVITU IEEE Events — Responsive Static Website
================================================

FILES
- index.html: page structure, visible interest-registration form, campus location and map
- style.css: responsive desktop/mobile styling
- script.js: navigation, event filters, form validation, local saving, CSV export

RUN
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Firefox, or a mobile browser.
3. Internet access is needed for remote photos, Google Fonts, and the embedded Google Map. Core page and form interactions work locally.

REGISTRATION FORM
- Includes name, email, phone, student ID, year, department, area of interest, event preference and consent.
- Validates required fields in the browser.
- Saves entries in localStorage on the current device/browser.
- “Download saved entries (CSV)” exports saved entries for testing/demo purposes.
- This is NOT a live registration system: no details are sent to VVITU or IEEE. For real registration, get organiser approval and connect an approved form/backend.

LOCATION / OFFICIAL LINKS
- Campus location: Nambur (Village), Pedakakani (Mandal), Guntur District, Andhra Pradesh, India.
- Official VVITU site: https://www.vvitu.ac.in/
- Official VVITU news: https://www.vvitu.ac.in/VVITU-News
- IEEE Day 2026 listing: https://events.vtools.ieee.org/m/529955
- Map: Google Maps search for VVITU, Nambur, Guntur.

IMPORTANT
This is a student-made concept website, not an official university/IEEE publication.
Past events are labelled. “Build Lab: Web & AI” is a concept showcase, not a confirmed event.
